# A brief for one research attempt

Adapted from the research-move and handoff templates used in this project.
Fill this out before starting a bounded attempt, then append the result.

## Claim

- State the exact conclusion, quantifiers, objects and normalization.
- List the hypotheses. Identify any external theorem inputs explicitly.
- Name the dependency this attempt would resolve and its intended consumer.

## Current evidence

- Link the current proof or reduction and the precise source version.
- Give the relevant theorem/section locator for each imported result.
- Record useful counterexamples and previously failed approaches.

## Attempt

- Describe one proposed mechanism or experiment.
- State what would count as success and what would rule out this route.
- Choose a bounded amount of work and a decisive check.
- If using Lean, first compare the intended objects with the formal statement.

## Return

- Conclusion: established / conditional / route failed / unresolved.
- Give the derivation, exact computation or counterexample.
- List every remaining assumption and external input.
- Preserve the useful proved prefix even if the route failed.
- Distinguish a refuted implication from a refuted target claim.
- Identify the next dependency and provide a self-contained handoff.
